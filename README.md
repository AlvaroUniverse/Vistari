# Sobre o Vistari

O Vistari vem como um projeto de um site raíz de frontend para uma coisa na qual pensei comigo em uma dúvida: "Em todo lugar aonde os navegadores vão, maioria do mundo vai pesquisar diretamente no Google onde é mundialmente conhecido, porém, e aquele pessoa que entrou na internet agora e não quer ser bombadiado por várias coisas, e queira um norte para seguir e finalmente explorar a internet?", assim surgiu o Vistari! O Vistari não é só uma *homepage*, e sim como uma central da internet!
<p align="center">"Novo por aqui? Passa no Vistari!"</p>
Assim eu gostaria de ouvir do que seria o Vistari.
